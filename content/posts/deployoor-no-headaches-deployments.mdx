## Deploy once, use everywhere

Placeholder section. `deployoor` turns a deploy into a single typed object you
can import anywhere — scripts, tests, and the app all read from the same
source of truth, so an address or ABI can't quietly drift out of sync.

```ts
import { contract } from "@/generated/deployoor"

// One typed object. Same address + ABI everywhere it's imported.
const token = contract("ConfidentialToken")
const balance = await token.read.balanceOf([owner])
```
